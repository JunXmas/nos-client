# Attribution

Crimson Oath geometry, rig, animation and original design: Nostalgia project. The wing and cape artwork were generated specifically for this collection using the image generation tool; originals are preserved in artwork/. They are not extracted from Lunar, Aurora, Badlion or another client.

Generated wing source: exec-3cfa2241-0cf1-48c5-9366-8bd527d46d9a.png.
Generated cape source: exec-deb999df-af80-4376-8da8-da2c6c16acc0.png.
Runtime atlases only resize/pack that artwork and sample its colours; compile_textures.py documents the UV layout.

The showcase mannequin uses the previous Minecraft Steve reference texture (Mojang Studios / Microsoft) for scale. The three individual cosmetic GLBs do not contain that skin or mannequin. It is not part of the cosmetic design.

The offline viewer bundles Three.js under MIT; see source/THREE-LICENSE.txt. Blender is used as an export/build tool and is not bundled.
