# Nos Client 0.4.3

- Sửa phần tô karaoke tràn vùng lyrics, đặt lại chiều rộng khi đổi câu và giữ khung trong cửa sổ.
- Cải thiện độ nét chữ Float/Sky bằng atlas mật độ cao, giữ các lựa chọn lyrics đã lưu.
- Thêm font **Be Vietnam Pro**, hỗ trợ dấu tiếng Việt và chữ tổ hợp NFC.
- Giữ kiểu lyrics Nos và font Nos Celestial làm mặc định.

Dành cho Minecraft **1.21.11**, Fabric Loader **0.19.3+**, Fabric API và Java **21+**.
Launcher tự tải bản tương thích khi bật Nos hoặc bấm Chơi; có thể cài thủ công jar vào `mods/`.

Đã kiểm build, 75 JUnit, dịch tiếng Việt/Anh, shader core và Minecraft thực tế với bộ FO
không Iris, gồm 24 font và các cảnh karaoke/Float/Sky. Lượt Iris cùng Complementary chưa
hoàn tất; không khẳng định tương thích mọi shaderpack. Chi tiết: `docs/qa-lyrics-sharpness.md`.
